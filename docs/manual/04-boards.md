# 4. Boards

Boards are the discussion areas, like forums. Each board has threads, and
each thread has replies in order.

Public boards are open to every user. Some you will find:
- The Pub: general chat, say hello here.
- Shared News: interesting links with a line about why.
- What's up?!: upcoming events and things going on.

Private boards are for invited people only. Press K in the board list to
start one. You own it and decide who may join. Other users cannot see it
or read it. The sysop has administrative access to the system, so treat it
as private among users, not as a vault.

Reading and writing:
- Pick a board by number, then a thread by number.
- A new thread asks for a subject, then the text. End it with a single .
- You can edit and delete your own posts. Sysops and the owner of a private
  board can also delete a post with every reply below it (type THREAD).
- # jumps to a post by its number inside a thread.

Some boards are read-only (for example automatic news). You can read them
but only the system posts there. Talk about the news on a normal board.
