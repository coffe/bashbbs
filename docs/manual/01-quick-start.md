# 1. Quick start

Five minutes to get going.

1. Press a number in the main menu to enter a part. No Enter needed.
2. Press ? on any screen to see which keys work there.
3. Press Q to go back one step. From the main menu it logs you out.
4. Say hello:
   - Wall (2): one short line, N to write, at most 140 characters.
   - Boards (1): The Pub is the place for a first chat.
5. Check Mail (5) for the welcome mail from the sysop.
6. Add a second SSH key in My Account (6) before you need it.
7. Files (8): D downloads and U uploads, both through a web link.

Everything else is in the chapters that follow. Start with chapter 3 if
the keys feel confusing.
