# 12. Downloading files

Normal downloads use a web link. The BBS gives you the link and your
browser does the transfer, so a phone works too. Terminal people have an
alternative, scp (chapter 14).

One file:
1. Open the area and the file, press D. (Or press D in the list and type
   the file's number.)
2. Press Enter at "LAST CHANCE!" to start.
3. Open the web link in a browser. The file is saved right away.

Many files:
1. In the list, press A on each file you want (or F on the file page).
   A + shows it is flagged. Up to 20 at a time. Flags are remembered.
2. Press D.
3. Open the link. You get a page where you tap each file to save it.

At "LAST CHANCE!":
  Enter  start
  G      start, and log out when the transfer is done
  A      abort

The link works for 15 minutes. Flagged files are unflagged once downloaded.
