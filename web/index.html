A tiny BBS. A little corner of the internet.

No algorithms. No endless scrolling. Just people, messages and a blinking cursor.

BashBBS is a message board you visit from a terminal window. It is written in Bash and runs on a Raspberry Pi Zero W. It's my project, my time, and it goes well with a cup of coffee. You're welcome to pull up a chair.

What's a BBS?

A BBS, a bulletin board system, is one computer that a handful of people visit to read and leave messages. There is no feed and no "for you" page. You log in, see what's new since last time, say something, and log out.

You get here with SSH, a program that is already on Windows, macOS and Linux. It opens a text window to another computer. You don't need to know anything about it beyond the one command further down.

A bit of history

In the 1980s and 90s people dialled into BBSes with a modem. Often the whole thing was one computer in someone's bedroom, and only one caller fit at a time. The person running it was the sysop. There were message boards, file areas, door games and ANSI art made by the demoscene.

BashBBS borrows the feeling, not the phone bill. The sysop here is coffe.

Join the BBS

There are no passwords here. You log in with a key instead. Three steps, about five minutes.

[1]

Get your key

Your key is like a house key with two parts. The public half goes on the door (that's us). The private half stays in your pocket. You only ever send the public half.

Pick your computer:

Windows 10 or 11
  1. Open PowerShell (Start menu, type powershell).
  2. Check if you already have a key: 
    dir $env:USERPROFILE\.ssh\*.pub
    If a file such as id_ed25519.pub shows up, you have one. Skip to the last step.
  3. No key? Make one: 
    ssh-keygen -t ed25519
    Press Enter at each question. A passphrase is optional but nice. If it asks Overwrite (y/n)?, answer n: you already had a key.
  4. Copy the public key: 
    Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard
    Now paste it in the form below.
macOS
  1. Open Terminal (Spotlight, type terminal).
  2. Check if you already have a key: 
    ls ~/.ssh/*.pub
    If a file such as id_ed25519.pub shows up, you have one. Skip to the last step.
  3. No key? Make one: 
    ssh-keygen -t ed25519
    Press Enter at each question. If it asks Overwrite (y/n)?, answer n.
  4. Copy the public key: 
    pbcopy < ~/.ssh/id_ed25519.pub
    Now paste it in the form below.
Linux
  1. Open a terminal.
  2. Check if you already have a key: 
    ls ~/.ssh/*.pub
    Found one? Skip to the last step.
  3. No key? Make one: 
    ssh-keygen -t ed25519
    If it asks Overwrite (y/n)?, answer n.
  4. Show the public key and copy the whole line: 
    cat ~/.ssh/id_ed25519.pub
Only the .pub file. The file without .pub is your private key. It stays on your computer and is never pasted anywhere, here included. If what you copied says PRIVATE KEY, it's the wrong one.
[2]

Apply

3 to 9 characters: lowercase letters and digits, starting with a letter. This is the name you log in with.

One line, starting with ssh-ed25519, ssh-rsa, ecdsa-sha2-… or sk-ssh-ed25519@openssh.com.

Not required, but it really helps: a line or two about yourself makes it much easier for me to tell a real person from a bot. How did you find the BBS? What are you into?

Email, Mastodon or similar, if you want a note when you're in.

[3]

Wait a little

A human (me) reads every application, usually within a day or so. Nothing is automatic, and that's on purpose. If you left a contact, I'll tell you when you're in.

Connect

Once you're approved, open the same terminal and type this, with your name instead of NAME:

ssh -p 6464 NAME@bbs.piewpiew.se

The old form bbs-NAME works too.

First login: what to expect
  1. SSH asks if you trust this computer. Check that the fingerprint matches, then type yes: 
    ED25519 SHA256:gmV5TjNQAQCYxc/SUyY8hwJMUhPnyeExywpfDlAjGVk
  2. The BBS asks once: Colour (ANSI) or plain ASCII? Colour looks like this page. You can change it later under My account.
  3. You land on What's new. Press any key for the main menu, and ? whenever you're lost.
  4. G says goodbye. Come back whenever.
It says "Permission denied"

Either the application isn't approved yet, or SSH is offering a different key. If your key is not the default one, point at it: ssh -i path/to/key -p 6464 NAME@bbs.piewpiew.se. Too many failed tries locks you out for an hour, so take a breath between attempts.
